# Contributing

Thanks for helping improve BrightPath Learning OS.

## Good First Contributions

- add demo-safe lesson examples
- improve TypeScript models for curriculum, progress, rewards, or identity
- add privacy regression tests
- document child-safe learning patterns
- improve accessibility and mobile layout guidance

## Privacy Rules

Do not contribute:

- real child photos
- real voice clips
- real learner progress
- school or family records
- credentials, tokens, `.env` files, or deployment metadata

Use demo-safe sample data only.

## Development

```bash
npm install
npm run typecheck
npm test
```

## Pull Request Checklist

- Tests pass.
- New sample data is fictional.
- No private asset paths are introduced.
- Documentation explains any new learning or privacy behavior.
